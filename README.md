# Bubuzinha Heart Particles

A small browser animation built with Vite and Three.js. The word **Bubuzinha** appears as a cloud of particles, explodes outward, and reforms into a heart in a looping 3D scene.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

 ## Build
 
 ```bash
 npm run build
 ```

## Deploy

This project is configured to deploy automatically to GitHub Pages on every push to `main`.
